YT Downloader

A free, point-and-click Windows app for downloading video and audio, built on the open-source yt-dlp library. Pick your settings here, and the app opens with them filled in.

Download for Windows Source on GitHub One ~60 MB file. No install, no account, no cost.

How it works

  
    
    
  1. The Windows app wraps yt-dlp in a simple window: paste a link, pick quality, click Download. It shows progress and lets you skip a video or cancel the whole run.
    2. 
    
  2. It bundles everything it needs (Python, yt-dlp and the deno JavaScript runtime YouTube now requires). A one-click Get ffmpeg button adds ffmpeg for 1080p+ and mp3 conversion.
    3. 
    
  3. This page runs entirely in your browser. It builds a ytdlp-gui:// link that Windows hands to the app, so your downloads happen on your own computer and connection.
    4. 
    
  4. The app and this site are built and hosted for free by GitHub Actions and GitHub Pages.
    5. 
  


  
Why there's no "download here" button

  
A website can't run yt-dlp: GitHub Pages only serves static files, and browsers block pages from fetching
    videos from other sites. A public server that downloads for anyone would cost money, get its IP blocked by YouTube
    quickly, and invite abuse. Running downloads on your own PC keeps this free and reliable.


  
Use it responsibly

  
Only download content you have the right to, such as your own uploads, Creative Commons or public-domain
    material, or where the site permits it. YouTube's Terms of Service restrict downloading outside its own features.
